# Capturas de proyectos

Las rutas del portafolio usan nombres numerados en orden:

## `alch/` — Gobierno / obras públicas

Coloca **12** capturas: `1.png`, `2.png`, … `12.png`  
(El orden en pantalla es el mismo que el número de archivo.)

## `cruz-verde/` — Cruz Verde

Coloca **4** capturas: `1.png` … `4.png`

## `solaino/` — Solaino (inventario / bodega / producción)

Coloca **13** capturas PNG en este orden:

| Archivo | Contenido |
|---------|-----------|
| `1.png` | Login / acceso (Supabase) |
| `2.png` | Panel administrador (módulos) |
| `3.png` | Inventario — resumen y alertas |
| `4.png` | Listado de productos |
| `5.png` | Ajuste de inventario |
| `6.png` | Registrar entrada |
| `7.png` | Embarque / salida |
| `8.png` | Nuevo producto |
| `9.png` | Solicitudes de inventario |
| `10.png` | Usuarios y roles |
| `11.png` | Historial (auditoría) |
| `12.png` | Historial por usuario / avance de proyectos |
| `13.png` | Bodega — OC, maquinado CNC y taller |

Puedes volver a copiar desde tu carpeta de trabajo, por ejemplo:

`Downloads\cv\gobierno\` → `public\media\alch\`  
`Downloads\cv\cruz verde\` → `public\media\cruz-verde\`  
`Downloads\img-porta\` → `public\media\solaino\` (`1.png` … `13.png`)
