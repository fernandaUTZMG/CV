# Capturas de proyectos

Las rutas del portafolio usan nombres numerados en orden:

## `alch/` — Gobierno / obras públicas

Coloca **12** capturas: `1.png`, `2.png`, … `12.png`  
(El orden en pantalla es el mismo que el número de archivo.)

## `cruz-verde/` — Cruz Verde

Coloca **4** capturas: `1.png` … `4.png`

## `solaino/` — Solaino (inventario / bodega)

Coloca **7** capturas PNG en este orden:

| Archivo | Contenido sugerido (como en tu portafolio) |
|---------|---------------------------------------------|
| `1.png` | Panel Inicio / administrador con módulos y Supabase |
| `2.png` | Módulo Inventario (alertas, búsqueda) |
| `3.png` | Listado de productos (tabla con columna IMG) |
| `4.png` | Bodega, vista por proyecto (FLEX) |
| `5.png` | Bodega, pestaña Orden (tiempos, avance %) |
| `6.png` | Historial (auditoría por usuario) |
| `7.png` | Usuarios (roles, recuperación de contraseña) |

Puedes volver a copiar desde tu carpeta de trabajo, por ejemplo:

`Downloads\cv\gobierno\` → `public\media\alch\`  
`Downloads\cv\cruz verde\` → `public\media\cruz-verde\`  
Tus capturas de **Solaino**: guárdalas tú como `public\media\solaino\1.png` … `7.png` siguiendo la tabla de arriba.
